ChatGPT Pro 从 2026 年 4 月 9 日起拆成了两档：Pro 5x 每月 100 美元，Pro 20x 每月 200 美元。搜索“5x 和 20x 区别”的人，多半在纠结同一件事：多出来的那 100 美元，到底买到了什么。

答案不复杂。两档用的是同一套模型，功能清单几乎一模一样，差别集中在两处：额度，以及桌面语音的时长限制。但围绕这笔账，过去半年发生的事情不少——计费方式改了，额度表更新了，20x 还在 9 月暂停了新购买。这些都直接影响你的决定，下面逐个说。

## 先说结论：模型一样，差的是额度和语音

Pro 5x 和 Pro 20x 都包含完整的 Pro 功能：Pro 系列模型、Codex、Deep Research、图像生成、记忆、大文件上传与分析。名字里的 5x 和 20x 指的是相对 Plus（$20/月）的额度倍数，跟模型智商、回答速度没有关系。官方文档对此说得很直白：买 20x 不会让同一个模型变更聪明，你买到的是大得多的用量池。

顺带纠正一个流传挺广的误解：市面上说的"Codex 100""Codex 200"套餐并不存在。Codex 是包含在 ChatGPT 套餐里的编码 agent，那两个价格是 ChatGPT Pro 的档位，仅此而已。

两档之间唯一明确写在官方文档里的功能差异是桌面端语音。Pro 20x 不限时长；Pro 5x 有限制，官方表格给的参考是每个滚动窗口大约 1–2.5 小时（也有资料写 3–6 小时，具体以你账号面板显示为准）。Plus 的语音每窗口大约半小时到一小时，差距主要在这。另外提醒一句：用语音发起的任务照样消耗 Codex 额度，语音并不是免费旁支。

还有一条旧信息需要清理：今年上半年 5x 曾限时按 10 倍 Plus 额度给，活动 5 月 31 日结束。现在官方文档写的就是干净的 5x 和 20x，再看到"5x=10x"的说法，先看日期。

## 官方额度对照表：5x 和 20x 到底差多少

OpenAI 价格页公布的是“每 5 小时本地消息”的规划区间，覆盖 Work 和 Codex 场景：

| 模型 | Plus（$20/月） | Pro 5x（$100/月） | Pro 20x（$200/月） |
| --- | --- | --- | --- |
| GPT-6 Astra | 5–45 | 25–225 | 100–900 |
| GPT-5.6 Sol | 10–100 | 50–500 | 200–2,000 |
| GPT-5.6 Terra | 25–200 | 125–1,000 | 500–4,000 |
| GPT-5.6 Luna | 250–2,000 | 1,250–10,000 | 5,000–40,000 |

（单位：每 5 小时的本地消息数，官方规划区间，非硬性上限）

规律很整齐：同一行里，Pro 5x 是 Plus 的五倍，Pro 20x 是 Plus 的二十倍，也就是 5x 的四倍左右。花两倍的钱拿到约四倍的名义额度，这是 20x 在纸面上的价值来源。

几个影响实际消耗的细节：

- GPT-6 Astra 是目前最强的模型，也是把窗口烧得最快的那个；Codex 云端任务目前跑的是 Sol，Astra 不参与云端任务。
- 计量方式在 4 月改成了与 API 对齐的 credit 制，模型之间费率差距很大——以输入为例，Astra 每 100 万 token 的费率大约是 Luna 的 50 倍。开 Fast mode 按 2.5 倍计费。
- 图像生成平均会让额度消耗快 3–5 倍。
- 官方给的参考值：一个典型的 Sol Codex 任务花 5–30 credits，开发者平均每月的 Codex 花费在 100–200 美元这个量级。

窗口机制也值得单独说。滚动 5 小时上限在 7 月一度被移除，8 月底恢复时只对 Plus 生效，Pro 两档目前主要受每周上限约束。换句话说，Pro 用户更常见的撞限方式是“周额度先见底”，而不是下午三点突然被掐断。Plus 用户两类窗口都在，两种墙都可能撞上。

把这些区间换算成任务更直观，还是以区间最紧、也最能代表重度工作的 Sol 为例：

| 任务类型（以 GPT-5.6 Sol 计） | 每任务交互次数 | Pro 5x 任务数 / 5小时 | Pro 20x 任务数 / 5小时 |
| --- | --- | --- | --- |
| 快速问答、小修改 | 2 次 | 25–250 | 100–1,000 |
| 起草、文档审阅、结构化分析 | 6 次 | 8–83 | 33–333 |
| 复杂研究、长编码会话 | 12 次 | 4–41 | 16–166 |

注意别只数 prompt 长度。一个 50K token 的任务如果一次交互完成，可能比反复调用工具、检索的短任务更省额度，按 token 大小做购买决策很容易翻车。

## 这笔价格账怎么算

把额度折成单价：Pro 5x 是 100 美元买 5 个“Plus 当量”，每份 20 美元；Pro 20x 是 200 美元买 20 个当量，每份 10 美元。纸面上 20x 的单位额度便宜一半。

前提只有一个：你真的用得掉。额度不用就是零，这是所有订阅制共同的坑。

判断升级是否回本，可以用这个框架：

> 升级价值 = 省下的溢出成本（credits 充值或 API 账单）＋ 省下的时间 ＋ 不被中断的交付 － 多付的 100 美元

如果你在 5x 上月月撞限、持续把溢出工作搬到按量计费的 API 或 credits 上，而且溢出账单接近或超过 100 美元，20x 大概率是省钱的那档。反过来，5x 的用量长期只用到一半，那 200 美元买的基本是心理安慰。

## 常见问题

### Pro 5x 一个月大概能干多少活？

按官方区间换算：如果每个 Sol 任务平均需要 8 次交互，Pro 5x 在一个 5 小时窗口内大约能完成 6–62 个任务，具体受上下文长度、工具调用和推理强度影响。

### Pro 20x 呢？

同样按 8 次交互估算，大约 25–250 个任务。长上下文、并行 agent 和 Fast mode 都会让消耗明显加快。

### Pro 有固定的 token 上限吗？

没有。官方不发布固定的 token 配额，计划内用量按额度与 credit 机制走。token 数适合用来估算工作量，没法直接换算成消息条数。

### 暂停期间能从 5x 升到 20x 吗？

不能。9 月 10 日起新购和升级一起停了。降级随时可以，但降了在暂停期内回不去。

### 买 20x，回答质量会更好吗？

不会。两档模型一样，档位只决定撞限之前你能跑多少，不影响单次回答的质量。
